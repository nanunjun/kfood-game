# FTUE — First-Time User Experience (튜토리얼)

> 버전: **v0.2** · 갱신일: 2026-05-24 · 작성자: ui-designer
> 상위 문서: [`screen-flow.md`](screen-flow.md), [`tier-1-2-flow.md`](tier-1-2-flow.md), [`../systems/cooking-mechanics.md`](../systems/cooking-mechanics.md) §10.1 #5, [`../systems/mvp-food-selection.md`](../systems/mvp-food-selection.md) §6.3, [`../art-style-guide.md`](../art-style-guide.md)
> **MVP scope**: Tier 1 진입 첫 4-step. 친구 unlock 컷씬(어머니/아버지 L11 동시)은 **FTUE 일부 아님** — §7에서 명시 분리.

## 0. 핵심 원칙

- **One-thumb / 5-second rule** 준수. 모든 step은 한 손가락 + 5초 안에 의도 파악.
- **Anchored CTA**: 각 step 끝에는 단일 highlighted 다음 액션 (선택 분기 없음).
- **Skip 정책**: Step 1 강제(skip 불가), Step 2~4는 우상단 `Skip All` 가능. 한 번 skip 시 영구.
- **광고 차단**: FTUE 5분 이내 Interstitial **무조건 차단** (GDD §5.2). Banner는 메인 메뉴 도달 후 노출.
- **첫 음식 = 호떡 lock** (v0.2, game-designer 권고 채택). 근거: 2가게(곡물+잡화) / 굽기 단순 / 시각 5/5.

## 1. FTUE 첫 음식 — 호떡 lock

| 후보 | 가게 수 | 재료 수 | 조리법 | Stage 3 cook_time | 결과 |
|------|--------|--------|--------|-------------------|------|
| **호떡** | **2 (🌾 곡물 + 🫙 잡화)** | 5 | 굽기 (지지기) | 8~10s | ✅ **LOCK (1순위 채택)** |
| 라면 | 3 (🥬+🌾+🫙) | 3 | 끓이기 | 8~10s | 2순위 (Step 2~3 또는 Round 2 후보) |
| 김밥 | 5 (전 가게) | 6 | 말기 | 3~5s | ❌ (FTUE에 5가게 풀 순회 부담) |

**호떡 lock 사유** (game-designer v2.0 권고 + mvp-food-selection §1.3-②):
- **2가게만** (곡물+잡화) = Step 1 단일 가게 introduction이 가장 부드럽다. Step 2에서 2가게 확장이 0 → 1 가게 추가가 아니라 호떡 그대로 2가게를 다 도는 자연 학습이 가능.
- 굽기/지지기 단순 = 단일 시각 메타포(프라이팬 + 누름주걱) 명료. Stage 2에서 첫 조리법으로 명료.
- 시각 매력 **5/5** (갈색 윤기 + 흑설탕 흐름) = Scene 3 첫 인상 SS급 → D1 retention 핵심 자산.
- 단맛 카테고리 단독 = 매운 진입 회피, FTUE 정서적 부담 0.

> **계란말이 제거 사유**: v2.0에서 음식 12개 reshuffle로 계란말이가 MVP에서 제외됨 (post-launch M1 alt). FTUE 첫 음식 1순위 자리는 호떡으로 lock.

> **라면 2순위 의의**: K-food 글로벌 SS급. 단 **3가게** 진입이라 Step 1 단일 가게 의도와 충돌. **FTUE 본 흐름 외 첫 Round (Round 2)** 또는 FTUE Step 2 확장 음식 후보로 보존. §4.2 참조.

## 2. 4-Step 흐름 (Overview)

```
[첫 부트 → Splash → Main Menu (skip) → Level 1 자동 진입]
       │
       ▼
┌──────────────────────────────────────────────┐
│ Step 1 — 단일 가게 raw introduction          │
│   Scene 1 입구(가게 1개만, 🌾 곡물 활성) →   │
│   가게 진입 → 재료 픽업 → 자동 진행           │
│   음식: 호떡 (raw, 곡물 가게만 활성)          │
│   → Step 1 한정 호떡 재료 부분집합(곡물 측만) │
└──────────────────────┬───────────────────────┘
                       │ Round 종료 후 (Scene 2·3 임시 skip)
                       ▼
┌──────────────────────────────────────────────┐
│ Step 2 — 다점포 개념 도입 (2가게)             │
│   가게 2개 활성 (🌾 곡물 + 🫙 잡화)           │
│   음식: 호떡 (이번엔 풀 2가게 순회)           │
│   → 같은 음식 반복 = 학습 강화                │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ Step 3 — Scene 2 키친 첫 등장                │
│   조리법 선택 UI 첫 노출 → Stage 3 timing    │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ Step 4 — Scene 3 식탁 첫 등장                │
│   점수 / ★ / "잘했어요" 피드백 첫 노출        │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
                [FTUE 종료, Level 1 정식 진입]
```

### 2.1 전체 소요 시간 목표

- Step 1: ~30s
- Step 2: ~45s
- Step 3: ~45s
- Step 4: ~30s
- **합계 목표: 2.5~3분** (FTUE 5분 이내 광고 차단 룰 안전 마진).

> **Step 1 호떡 raw introduction 노트**: 호떡 본 SKU는 곡물(밀가루) + 잡화(이스트/설탕/견과/계피) = 2가게 5재료. Step 1은 **곡물 측 정답 1~2개만** 노출(FTUE 한정 부분집합). Step 2에서 잡화점 추가 활성 시 잔여 재료 픽업 = 같은 음식 학습 강화.

### 3.2 Step 1 룰

- **타이머 표시 없음** (압박 제거).
- **오답 카드 비활성** (정답만 탭 가능 — 첫 인지 부담 0).
- **정답 글로우 표시** (cooking-mech §2.4 룰 예외 — FTUE 한정).
- **공통 타이머 비표시** (Stage 1 핵심 UI는 step 2부터 노출).
- **Scene 2·3 자동 스킵**: Step 1 종료 직후 Step 2 ramp-up 모달로 이동 (조리·식탁은 step 3·4에서 첫 노출).

### 3.3 Step 1 anchored CTA & 사운드 hook

| 시점 | CTA / 안내 | 사운드 hook |
|------|----------|------------|
| 입구 진입 | "곡물상에 가볼까요?" + 👆 | 🔊 `ftue_voiceover_step1` (TBD) |
| 가게 진입 | (자동, 안내 없음) | 🔊 가게 진입 종소리 |
| 정답 탭 | "밀가루를 골랐어요!" | 🔊 `pickup_chime` |
| 곡물 측 픽업 완료 | "다음 가게도 둘러봐요!" 토스트 | 🔊 `step_complete` |

## 4. Step 2 — 다점포 개념 도입 (2가게)

### 4.1 화면 흐름

```
[Step 1 종료 직후, 짧은 모달 0.8s]
   │
   ▼
┌────────────────────────────────────────┐
│  💡 "이번엔 2개 가게를 둘러봐요"        │
│        [ 좋아요 ]                       │
└────────────────────────────────────────┘
   │ 탭
   ▼
┌────────────────────────────────────────┐
│  📝 요리 카드: "🥞 호떡 (1인분)"        │
│     (같은 음식 반복 = 학습 강화)         │
├────────────────────────────────────────┤
│   ┌──┐       ┌──┐                      │
│   │🌾│       │🫙│  ← **2개 활성**       │
│   │곡│       │잡│                      │
│   │물│       │화│                      │
│   └──┘       └──┘                      │
│   ┌──┐ ┌──┐ ┌──┐                       │
│   │🔒│ │🔒│ │🔒│  ← 3개 회색 잠금       │
│   └──┘ └──┘ └──┘                       │
│                                        │
│   💬 "두 가게를 다 다녀와야 해요"        │
│   ⏱ ▓▓▓▓▓░░ 25s (타이머 첫 노출)       │
└────────────────────────────────────────┘
```

### 4.2 Step 2 룰

- **2가게 활성** (🌾 곡물 + 🫙 잡화) — 호떡 정답 분포(밀가루 + 이스트/설탕/견과/계피)에 정확히 fit.
- **타이머 첫 노출** (25s, 넉넉 — 압박 최소화).
- **정답 글로우 OFF** (탐색 학습 시작).
- **오답 탭 활성** (페널티는 있으나 빨간 shake로 학습).
- **빈 가게 진입은 트리거 X** (활성 2가게 모두 정답 있음).
- 모든 정답 픽업 → 자동 입구 복귀 → Step 3 모달.

### 4.2.1 Step 2 음식 권고 재검토 (v0.2 노트)

> **결론: Step 2도 호떡 그대로 유지 권고.** 호떡 자체가 2가게(곡물+잡화) raw → Step 1(곡물만) → Step 2(곡물+잡화 풀) 동일 음식 반복으로 학습 강화. 별도 음식 swap 불필요.

- **검토했던 대안**: Step 2에 호떡 외 "다른 가게 1개를 추가하는 음식"을 도입(예: 라면 = 🥬+🌾+🫙 3가게) → **거절**. Step 2 한 step에서 음식 swap + 가게 1개 추가 동시 학습은 인지 부담 ↑, 5-second rule 위배.
- **김밥 step 3 미루기**: 김밥은 5가게 풀 순회 = FTUE에 부적합 → 본 문서 §1 표에서 이미 제외. Step 3는 Scene 2 키친 첫 등장이므로 음식 swap 자체가 일어나지 않음(호떡 그대로 키친 → 굽기).
- **단순 음식 후보 (Step 3+ 본 게임 Round 2 진입 시 권고)**: 라면(3가게, 끓이기) → 떡볶이(4가게, 끓이기, 어물전 데뷔)는 game-designer §3 난이도 곡선과 동기. FTUE 4-step은 호떡 단일 음식으로 통일.

### 4.3 다점포 안내 반복 (cooking-mech §10.2 follow-up)

> **결정: 다점포 안내는 FTUE Step 2에서 1회만 강제. 이후 Round 2~3에서 미세 hint 1회 반복.**

| Round | 다점포 hint |
|-------|------------|
| FTUE Step 2 | "두 가게를 다 다녀와야 해요" (강제 모달, 스킵 불가) |
| FTUE 종료 후 Round 2 (계란말이 또는 라면) | 입구 진입 시 토스트 "가게 여러 곳을 둘러봐요" 2.0s (스킵 가능) |
| Round 3+ | 미표시 (학습 완료 가정) |
| **김밥/떡국(5가게 풀 순회) 첫 등장 시** | 요리 카드 옆 ⓘ 아이콘 + "이 요리는 5가게 모두 필요해요" 토스트 |

⚙️ **확정 필요**: Round 2 미세 hint 횟수 — 1회 vs 2회 (Round 2·3 모두).

## 7. 친구 unlock 컷씬 — FTUE 일부 아님 (혼동 방지)

> **명시 (v0.2 갱신)**: 어머니/아버지 동시 unlock 컷씬은 **L11 Tier 2 진입 시점**에 1회성 트리거되며, FTUE 4-step과는 **별개**.

- FTUE = Level 1 첫 1 Round 한정 (Step 1~4, 호떡).
- **어머니 + 아버지 동시 unlock** = L11 Round 1 직전 1회성 컷씬 ([`tier-1-2-flow.md`](tier-1-2-flow.md) §3.4). v0.1의 "어머니 L11 / 아버지 L15 분리" 권고는 **폐기** (game-designer 권고 채택 → Tier 2 진입 = 가족 식탁 풀 등장).
- 컷씬 skip 가능, FTUE의 `Skip All` 과는 독립.

이유: FTUE는 **메커닉 학습**, unlock 컷씬은 **정서 arc 발화** (혼밥 → 가족). 두 목적이 다르므로 UX 분리. 양친 동시 unlock은 Tier 경계의 정서 임팩트를 단일 컷씬에 집중하여 분산을 피한다.
