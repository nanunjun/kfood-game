# Phase 1 — 프로덕션 우선순위 & 폴리시 체크리스트

> 사용자 확정: **시간·공수의 대부분을 3개 폴리시에 투자.** "이 게임 손맛 좋다"가 가능해야 함. 무엇을 깎을지 고민되면 이 3개는 **절대 깎지 않는다.**
> 공수 배분 가이드: **코어 폴리시 60% · 기능 시스템 30% · 운영·메타 10%.**

## 1. 리듬 입력 손맛 (Tactile Feel) — 최우선
무너지면 게임 자체 실패.
- [ ] **5중 히트 피드백**: 화면 미세 진동 + 노트 폭발 파티클 + SFX + 색상 글로우 + 점수 팝업(동시).
- [ ] **판정 차등 시각**: Perfect=금색 빛+정중앙 폭발 / Good=부드러운 펄스 / Miss=모서리 미세 셰이크+회색. 무의식 학습.
- [ ] **노트 강하**: 일정 속도 + easing, 흔들림 없음, **60fps 보장 최우선**.
- [ ] **양념 게이지**: 탭마다 칸 "딸깍" 채워짐(시각+청각), 양념별 색·재질·SFX 차등.
- [ ] **SFX layering**: 칼질(목제 톡)·양념(가루 사르륵)·끓음(보글)·플레이팅(그릇 짤랑) 각 정성 레이어드. CC0 인제스트 후 **추가 layering 패스 필수**.
- [ ] **햅틱/진동**: Perfect=짧고 단단 / Miss=길고 부드러움. 모바일 light haptic preset.

## 2. 음식 완성 연출 (Food Reveal) — 1.5~2.5초, SNS·광고 소스
- [ ] **입자 모션**: 메뉴별 — 찌개=보글 연기+미세 흔들림 / 부침=기름 광택 / 면=윤기 흐름.
- [ ] **카메라**: 살짝 줌인 + 약간 기울기, 한 박자 멈춤("타다~").
- [ ] **글로우**: 음식 위 황금톤 림라이트. 특산품·Pro 도구 사용 시 글로우 강화.
- [ ] **이펙트+SFX 결합**: 완성 종(놋그릇 톤)+빛 번짐+김, 한 박자.
- [ ] **완성 sting 3등급**: 보통/잘함/명품(점수 등급 변주).
- [ ] **메뉴 12개 각 reveal 개별 디자인**(각 5~10초라도 정성).

## 3. 플레이팅 연출 (Plating) — 5초, snap 감각
- [ ] **그릇 선택**: 캐러셀 좌우 스와이프, 선택 시 그릇 떠오름 + soft chime.
- [ ] **담기 애니**: 음식이 위에서 부드럽게 안착, "스윽 차르륵" SFX.
- [ ] **매칭 보너스 reward**: 권장 그릇 → 빛 번짐 + "+15% Match!" 팝업 + 화음. 미스매치 → 부드러운 1단 낮은 음.
- [ ] **garnish 1슬롯**(Phase 1 단순화): 선택 즉시 음식 위 톡 안착.
- [ ] **결과 연결**: 플레이팅 완료 1초 카메라 정지 → reveal과 매끄럽게 연결.

## 4. 상대적으로 functional만 (시간 절약)
| 영역 | 기준 |
|---|---|
| 인벤토리 UI | 정보 명확하면 OK, 화려함 X |
| 시장 UX | 가판대 위젯 정도, 풀 일러스트 X |
| 손님 입·퇴장 | 가벼운 fade + 한 줄 대사 |
| 잠금 알림 | 표준 토스트 + 한 줄 |
| 세팅·메뉴 | 표준 모바일 UI |
| 평판 표시 | 숫자/별 단순 |
| 시장 BG | 정적 이미지 + 미세 ambient loop(시차 모션 X) |

## 5. 의사결정 룰
- 일정 압박 시 컷 순서: 운영·메타 → 기능 시스템 주변부 → (절대 마지막) 코어 폴리시 3.
- 신규 요청이 들어와도 "이게 3대 폴리시를 깎는가?"를 먼저 점검.
- 사운드: `sound-guide §SFX layering`, `audio-pipeline-v1`(박자 정렬) 준수 — 손맛의 절반은 오디오.
