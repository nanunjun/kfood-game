# marketing/

스토어 등록 및 마케팅 자산.

## 무엇을 두는가
- **Google Play 메타데이터**
  - 앱 제목, 짧은 설명(80자), 자세한 설명(4000자)
  - 한국어 / 영어 / 일본어 등 다국어 버전
- **스토어 스크린샷**: 1080×1920 또는 1080×2400 (최소 2장, 권장 8장)
- **피처 그래픽**: 1024×500
- **앱 아이콘**: 512×512 (스토어용), 적응형 아이콘 원본
- **프로모 동영상**: 30초 이내
- **광고 크리에이티브**: 페이스북/유튜브/틱톡 광고용 영상·이미지
- **ASO 키워드 리서치 결과**

## 구조 예시
```
marketing/
├── store/
│   ├── google-play/
│   │   ├── ko/
│   │   ├── en/
│   │   └── ja/
│   ├── screenshots/
│   └── icons/
├── ads/
│   ├── facebook/
│   ├── tiktok/
│   └── youtube/
└── aso/
    └── keywords.md
```

## 참고
- 스토어 정책 변경 잦음 → 업로드 직전 공식 가이드 재확인
- A/B 테스트할 아이콘/스크린샷은 버전 suffix 사용 (`icon_v1.png`, `icon_v2.png`)
