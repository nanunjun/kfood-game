**핵심 발견 (v1.3)**:
- **잡화점 음식 등장 12 → 10** (떡볶이·잡채 강등). 떡볶이는 고추장 1개만 잡화에 있었기에 basic_pantry 제거 시 잡화 0 → 곡물(떡)+청과(파·양파)+어물(어묵) 3가게로 fingerprint 정제. 잡채는 간장·참기름 둘 다 basic_pantry라 잡화 0 → 청과(4)+정육(1)+곡물(1) 3가게.
- **잡화점 평균 정답 2.42 → 1.7** = 청과(2.45) 단독 dominant 가게 패턴 명확화. v1.2까지는 잡화-청과 dual dominant였으나 v1.3에서 잡화는 어물(1.6)과 비슷한 mid-tier 가게로 자연 위치.
- **basic_pantry 정책의 Stage 1 인지 부하 감소**: 사용자가 매 음식마다 "고추장? 간장? 설탕?" 같은 한식 base 양념을 매번 잡화점에서 픽업하는 반복 노동 제거 → 음식별 unique signature 재료(어물 멸치 / 정육 얇은소고기 / 곡물 소면 등)에 집중 가능.
- **Stage 1 distractor pool 영향**: 잡화점 SKU 17종 → 12종 (basic_pantry 5종 제거). distractor_per_store_by_tier=[1,1,2,2,3] 기준 T1 1개·T2 1개 distractor 충분 (잡화 12종 중 정답 1~4 + distractor 1 = 2~5 표시 시 잡화 비어 보이지 않음).
- **어물전 floor 5 유지**: basic_pantry는 sundry만 영향, seafood 무영향.
- **5가게 풀 순회 음식 (김밥) 유지**: 김밥 정답 5가게(파·햄·김·밥·계란+단무지)에 basic_pantry 0이라 영향 없음.

## X. Basic Pantry 제외 정책 — C-2 LOCK 2026-05-31 (신설)

### X.1 정의

**Basic pantry** = 모든 한국 가정 부엌에 상시 비치된 base seasoning 5종. Stage 1 재래시장 진열대에 표시하지 않고, Scene 2 kitchen 진입 시 **kitchen rack** UI에 자동 표시한다 (사용자 선택 행위 X, 시각 cue만).

### X.2 정책 룰

1. **Stage 1 재래시장**: basic_pantry 5종은 잡화점 진열대에 **표시하지 않음**. distractor pool에서도 제외 (음식별 정답 재료에 포함되어 있더라도 픽업 대상 아님).
2. **Scene 2 kitchen 진입 시**: kitchen rack UI에 basic_pantry 5종 항상 표시 (시각 cue / 자동 적용). 사용자 행동 X.
3. **accuracy_ingredients 분모 N**: foods-database의 ingredients 배열에서 basic_pantry 5종을 **자동 차감**한 후의 N으로 계산 (cooking-mechanics §2.5 sync).
4. **friends-system 호불호 axis**: basic_pantry는 axis trigger 가능 (간장 = salty, 설탕 = sweet, 고추장 = spicy 등) — 정책 무영향 (호불호는 음식 단위 판단).
5. **Stage 2A rhythm tap**: basic_pantry 단독으로 hero ingredient 선택 X (양념재우기 60 BPM은 hero가 thin-slice beef + 양념 마사지 통합 행위라서 별도 처리, cooking-mechanics §X 양념재우기 정합 명시 참조).
