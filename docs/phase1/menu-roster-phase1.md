## 2. W2 대비 변경 (정합)
- **재사용 9**: 라면·김밥·떡볶이·잔치국수·비빔밥·잡채·불고기·해물파전·순두부찌개 (premium 아트 완료).
- **교체 3**(노량진/한식 깊이 매칭): 콘도그(t1_007)·김치볶음밥(t1_005)·갈비구이(t2_012) → **김치찌개·된장찌개·매운탕**. 빠진 3종은 Phase 2 archive 또는 후속 추가.
- 신규 3종 완성샷 프롬프트 = `image_prompts_phase1.md`(검정 컷아웃). 나머지 9종은 기존 `art/sprites/food` 재사용.

## 3. 노량진 매칭
- **해물파전**(●해물)·**매운탕**(●생선) = 노량진 개방(L4) 후 해산물 재료로 매칭. 평판↑ 시 특산품(죽방 멸치 등) 해제.
- 잔치국수·순두부(△)는 멸치 육수로 노량진 연계 가능(동네에서도 기본 멸치 구매 가능).

## 4. 재료 티어 (Phase 1 = 2티어)
Basic + 특산품만. 명품(3티어)은 Phase 2. 특산품 예: 영양 고춧가루·신안 천일염·의성 마늘·죽방 멸치(노량진). 횟수제 소모 유지.

## 5. reveal 연출 메모 (production-priorities §2)
메뉴별 완성 연출 키워드(아트 키프레임, `image_prompts_phase1`):
- 찌개류(김치/된장/순두부/매운탕): 보글 연기 + 미세 흔들림 + 옹기 김.
- 부침(해물파전): 기름 광택 글로우.
- 면(라면/잔치국수): 윤기 흐름 + 김.
- 볶음/구이(잡채/불고기): 윤기 + 황금 림라이트.
- 비빔밥: 색채 폭발 + 돌솥 김.
- 김밥/떡볶이: 글로시 윤기, 김밥은 단면 색대비.
