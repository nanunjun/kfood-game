## 1. North Star — canonical reference 정밀 서술

> **모든 art-director / gen 작업자는 작업 전 `assets-raw/style/north_star_hanhana_v1.png` 를 직접 본다.** 본 절은 그 그림의 텍스트 사양(그림 분실/재생성 시 복원 기준).

### 1.1 한 줄 정의 (v2)

> **"따뜻한 한식 home kitchen 안, 캐릭터 셰프 '한하나'가 뚝배기 순두부찌개를 젓는 storybook 한 장면 — soft volumetric shading, warm 나무·옹기·장독·세이지 그린 팔레트, layered depth 가 살아있는 cozy premium-casual 2D 한식 요리 세계."**

- v1 의 3축(`warm` + `cozy` + `premium-casual`)을 그대로 계승하되, **추상 무드 → 구체 한 장면**으로 못박음.
- 핵심 차이(v1 대비): (a) **캐릭터가 주방 world 안에 존재**(빈 BG anchor 가 아니라 캐릭터+음식+환경이 한 장면), (b) **환경 밀도/depth 상향**(선반 그릇·옹기·장독·도구통·뒤쪽 또 다른 요리사까지), (c) **음식이 vessel(뚝배기) 안에서 실제로 끓는다**(steam·broth·재료).

### 1.2 reference 캐릭터 "한하나" (꽃가마 한식 셰프) — **스타일 예시 사양 (고정 마스코트 아님 — §4 참조)**

> ⚠ 한하나는 **북극성 톤/렌더/주방 세계감의 STYLE 예시일 뿐**, 게임 주인공이 아니다. 주인공 = 플레이어 성별 선택 셰프 2종(§4). 아래는 reference 그림의 복원 기준이며, 신규 주인공에 한하나의 분홍 꽃핀/세이지 앞치마/태극기 patch/자수 텍스트는 복제하지 않는다.

| 요소 | 사양 |
|------|------|
| 인물 | 젊은 한국 여성 셰프, 둥근 소프트 얼굴, 발그레 warm 볼, 큰 따뜻한 갈색 눈(흰 하이라이트 1점), 친근한 활짝 웃음 |
| 머리 | 진갈색 단발/묶음, **분홍 꽃 hair pin** (시그니처 액센트) |

### 1.3 배경 (따뜻한 한식 home kitchen) — 밀도/depth 사양

- **선반/벽**: 나무 선반 + 쌓인 도자기 그릇(한국 문양), 옹기/장독, **빨간 고추장 통 "고추장"**, 나무 주걱/국자 꽂힌 도구통, "꽃가마 한식" 포스터, 타일 백스플래시.
- **카운터**: 도마+대파, 화분 채소, 토마토 볼, 양념병, 스테인리스 가스레인지(파란 불꽃).
- **depth**: 뒤쪽에 또 다른 요리사(depth 레이어), 따뜻한 조명, 전경 카운터 → 중경 셰프 → 후경 주방 의 3단 이상 layered depth.
- **금지**: beige void(빈 베이지 배경), flat 단색 배경, 캐릭터만 떠있고 환경 0.

### 1.4 렌더링 사양

- soft volumetric shading, warm 팔레트, storybook illustration, **clean linework**(warm dark outline, 순흑 X), appetizing(음식 식욕·highlight), handcrafted, **layered depth**.
- **금지(non-style)**: flat vector / photoreal / 3D render / harsh neon / cool-mint 지배 / corporate beige empty.

## 4. 주인공 = 플레이어 아바타 2종 (성별 선택) — 한하나는 STYLE 예시일 뿐

> **🔒 사용자 LOCK 정정 (2026-06-08)**: 이전 §4(한하나 = 고정 host/마스코트 채택 권고)는 **폐기**. `north_star_hanhana_v1.png` 의 **"한하나" = 스타일 예시(reference)일 뿐 — 그대로 주인공으로 쓰지 않는다.** 북극성은 **톤/렌더 품질/주방 세계감 기준**(warm storybook, cocoa outline, soft volumetric, 한식 주방 정체성)으로만 활용한다.

### 4.1 결정: **주인공 = 플레이어 아바타, 성별 선택 → 여자 셰프 1종 + 남자 셰프 1종 (신규 2종)**

- 게임의 얼굴 = **플레이어 자신의 셰프 아바타**. 플레이어가 게임 진입 시 **성별을 선택**한다.
- **여자 셰프 1종 + 남자 셰프 1종** (둘 다 필요) — 한하나 복제 X, **신규 정체성**(헤어/얼굴/복장 색 차별화).
- 두 캐릭터는 **같은 시각 언어**(동일 cocoa outline / soft volumetric / warm palette / storybook 얼굴 톤) — 성별·헤어·복장 색만 다르고, 나란히 놔도 한 게임.
- **한하나 시그니처는 신규 주인공에 넣지 않는다**: 분홍 꽃핀 ✕, 세이지 앞치마 ✕(여 셰프 = persimmon/terracotta 앞치마로 차별화), 태극기 patch ✕, "꽃가마/한하나" 자수 텍스트 ✕ (i18n icon-first lock — **텍스트 art 회피**). 단, style(톤/렌더/outline/주방 세계감)은 북극성 정합.

**근거**:
1. **플레이어 동일시 + 성별 선택 = 캐주얼 표준**: 고정 마스코트보다 플레이어가 "내 셰프"를 고르는 쪽이 몰입·리텐션에 유리. 성별 선택은 글로벌 캐주얼에서 기대되는 옵션.
2. **북극성 = STYLE seed (NOT 고정 캐릭터)**: canonical reference 는 *톤/렌더 품질/주방 세계감*의 기준. 주인공은 이 톤 위에서 **신규로 디자인**해 한하나 IP 종속을 피한다.
3. **i18n icon-first 정합**: 신규 셰프는 텍스트(자수/patch) 없이 "한식 셰프 복장(자켓+앞치마) + 주방 톤"으로 정체성을 전달 — 글로벌 first impression 유리.

- **7 guest(Junho/Mina/...) = 손님**(먹고 reaction). **주인공 2종(요리하는 쪽) ↔ guest(먹는 쪽)** = 게임 루프 양측, 충돌 없음. 단 **모두 같은 시각 언어**(cocoa outline / soft shading / warm palette / storybook 톤)로 렌더해야 한 IP.
