## 2. 재료 = 횟수제 소모품
각 재료는 **1회 구매 = `uses_per_purchase`회 사용**, 0 되면 회색 처리·재구매 전까지 해당 메뉴 잠금. **실패해도 소모, 부분 환급 없음**(전략적 긴장).
> 근거: 횟수제 = 재고 관리 레이어 + 명품 남용 억제(비싸고 적게 씀). 환급 없음 = 신중한 양념·재료 선택 유도.

## 3. 만족도 → 보상 곡선
레벨별 기본 보상 `payout_base`(다인·난이도 반영) × 만족 배수 `m`.
```
reward = round( payout_base[level] · m(S) )      # 실패 시 reward=0, 재료는 이미 소모
profit = reward − Σ(이번 라운드 소모 재료 1회당 실비용)
```
| 만족 결과 | 배수 m |
|---|---|
| 실패(S < θ_pass) | 0 (손실) |
| 통과(θ ≤ S < θ+0.05) | 1.0 |
| 우수(S ≥ θ+0.05) | 1.3 |

| Lv | payout_base(원) | 다인 | 비고 |
|---|---|---|---|
| L1 | 6,000 | 1 | 입문 |
| L2 | 7,000 | 1 | |
| L3 | 8,500 | 1 | |
| L4 | 10,000 | 1 | 특산품 진입 |
| L5 | 12,000 | 1 | |
| L6 | 14,000 | 1 | |
| L7 | 17,000 | 1 | |
| L8 | 21,000 | 2 | 다인 시작(×인원 반영) |
| L9 | 26,000 | 2~3 | 명품 필수 |
| L10 | 32,000 | 3 | 골든스푼 진입 |
| L11 | 40,000 | 3 | 전통 명품 |

> 다인 보상 = payout_base에 인원 배수 기반영. 후반은 명품 원가가 커서 **순익률은 유지/긴장**되도록 설계(아래 시뮬).

## 4. 명품 게이트의 경제적 의미
L9+는 명품 1회당 8,000~22,500원이 원가에 들어가지만 보상이 26,000~55,000원으로 커서 순익은 (+). 단 **실패 시 명품도 소모 → 큰 손실** → 정밀 플레이 압박. "고급 재료를 쓰되 정확해야 한다."

## 5. 진행 페이스 시뮬레이션 (L1·L4·L7·L10·L12 샘플, 재고 추적)
시작 잔고 50,000. (간략화: 라운드당 핵심 소모 재료만 표기)

| 라운드 | 레벨/손님 | 메뉴 | 구매(신규) | 소모(1회분) | 만족 | 보상 | 잔고 | 재고 메모 |
|---|---|---|---|---|---|---|---|---|
| R1 | L1 엄마 | 라면 | 쌀·간장·고춧가루(일반) 9,500 | 850 | 0.81 우수 | 6,000×1.3=7,800 | 50,000−9,500+7,800=**48,300** | 쌀12·간장12·고춧10 재고 확보 |
| R2 | L4 새콤친구 | 잔치국수 | 멸치육수(특산품 영양?) 12,000 + 소면 4,000 | 3,000+667 | 0.70 통과 | 10,000×1.0=10,000 | 48,300−16,000+10,000=**42,300** | 멸치육수 4회·소면 6회 |
| R3 | L7 블로거 | 갈비구이 | 의성마늘 9,000 + 소고기 7,000 | 1,800+1,400+(설탕133) | 0.82 우수 | 17,000×1.3=22,100 | 42,300−16,000+22,100=**48,400** | 특산품 마늘 5회 |
| R4 | L10 평론가 3인(다인) | 떡볶이 코스 | 순창 고추장(명품) 28,000 | 9,333+(설탕133)+(어묵667) | All-pass 0.93 통과 | 32,000×1.0=32,000 | 48,400−28,000+32,000=**52,400** | 명품 고추장 3회(2회 남음) |
| R5 | L12 마스터셰프 4인 코스 | 불고기+잡채+α | 횡성한우(명품) 45,000 | 22,500+9,333(고추장 잔여)+… | All-pass 0.98 우수 | 55,000×1.3=71,500 | 52,400−45,000+71,500=**78,900** | 한우 2회, 명품 잔여 추적 |
> 관찰: 초반은 소액 흑자 누적, 중반 특산품 투자로 잔고 횡보, 후반 명품 대량 투자지만 다인 고보상으로 큰 흑자 — 단 **실패 1회 시 명품 소모로 −2~4만 손실** → 정밀 압박. 페이스 = "벌어서 더 좋은 재료에 재투자".

> 위 수치는 디폴트 초기값. 실제 플레이 데이터로 payout_base·배수·재료가 튜닝 예정.

## 6. 조리 도구 — 티어 / 구매 / 어워드
도구 9종을 3티어로. **기본=시작 보유, 프로=구매, 마스터=어워드 전용(구매 불가)**. 효과 수식은 `scoring-v2.md §9`.

### 6.1 프로 도구 가격표 (구매)
| 도구 | 프로 구매가(원) | 핵심 효과(프로) |
|---|---|---|
| 양념 국자/주걱 | 50,000 | 양념 편차 흡수 ±0.05 (미식가 효자) |
| 칼 | 35,000 | Perfect 윈도우 100→130ms |
| 도마 | 30,000 | 칼질 콤보 ×1.1 |
| 냄비 | 40,000 | 끓이기 Miss 페널티 100→80% |
| 팬 | 38,000 | 볶기/부치기 Miss 페널티 100→80% |
| 웍(stirfry) | 45,000 | 볶기 콤보 안정화 |
| 튀김솥(deepfry) | 55,000 | 튀김 타이밍 관용 |
| 김발(roll) | 32,000 | 말기 콤보 보너스 |
| 양념볼(mix/toss/marinate) | 60,000 | 비비기·무침 편차 흡수 보조 |
> 가격대 30,000~80,000. 마스터 도구는 **가격 없음(어워드 전용)**.

### 6.2 구매 우선순위 가이드
1. **양념 국자/주걱(50,000)** — 편차 흡수가 미식가 통과에 가장 직접적. 중반(특산품 진입 L4~L7) 1순위.
2. **칼(35,000)** — Perfect 윈도우 확대로 손질 점수 안정. 2순위.
3. **냄비/팬(38~40,000)** — 타이밍 Miss 손실 감소. 3순위.
4. **도마(30,000)** — 콤보 보너스, 여유 자금 시.
> 근거: 후반 좁은 편차(0.085~0.05)는 **편차 흡수 도구 + 명품 재료** 조합 없이 통과 불가 → 국자/주걱·양념볼 우선 투자가 합리적.

### 6.3 마스터 도구 = 어워드(레벨 클리어 보상, 구매 불가)
| 어워드 레벨 | 획득 마스터 도구 | 효과(마스터) |
|---|---|---|
| L5 클리어 | 명품 칼 | Perfect 윈도우 160ms |
| L7 클리어 | 명품 도마 | 칼질 콤보 ×1.25 |
| L9 클리어 | 명품 냄비/팬 | Miss 페널티 60% |
| L10 클리어 | 명품 국자/주걱 | 편차 흡수 ±0.08 |
| L11 클리어 | 잔여 마스터 1종(웍 or 김발) | 각 효과 최대치 |
| L12 클리어 | 잔여 마스터 1종 + **트로피** | 〃 |
| 전 마스터 수집 | **메타 어워드: "한식 명인" 칭호** | 엔딩 후 자유플레이 보너스(보상 +10%) |
> 근거: 마스터 도구는 돈으로 못 사고 실력(레벨 클리어)으로만 → 명예/성취 동선. **마스터 국자/주걱(±0.08 흡수)은 L10에 줘서**, 그 이후 골든스푼 게스트(편차 0.07~0.05)를 명품 재료와 함께 겨우 통과하도록 균형.

### 6.4 미식가 통과 = 마스터 도구 + 명품 재료 (필수 조합)
L11 C14(편차 0.07): 마스터 국자/주걱 흡수 +0.08 → τ_eff=0.15. 완벽 입력 raw≈0.96. 전통 명품 보너스 +0.20 불가(상한) → +0.20 적용 시 S=1.0 ≥ θ0.95 **통과**. 마스터 도구 없으면 τ_eff=0.07 → raw≈0.88, 명품 더해도 S≈0.97 경계 — 실패 리스크 큼. ⇒ **마스터 도구 + 명품 재료**가 사실상 필수.

## 8. 시장 가격 · 평판 할인 · 이벤트 (허브 경제)

|---|---|---|
| 청과(채소·과일) | 가락동 기준가 | 타 시장 +15~25% |

> 근거: 전문 시장을 찾아갈 동기 = 더 싸고 좋은 재료. 동선·허브 형성.

## 9. A/B 미결
