# Monetization v1 — 무료 본편 + 광고 보상 + 선택적 DLC

> 정체성(한식 문화 컬렉션 게임)과 정합하는 수익화. **가챠·확률형 없음.** 무료 본편으로 끝까지 플레이 가능, 광고는 보상형 선택, DLC는 고정 콘텐츠 컬렉션 확장.
> 연동: `economy-balance-v1`(자금·재료), `unlock-tree-v1`(콘텐츠), `GDD-v2 §11`.

## 1. 광고 — Rewarded Ads (전부 선택적, 강제 없음)
| 보상형 광고 | 보상 | 트리거 | 비고 |
|---|---|---|---|
| 재료 보충 | 선택 재료 사용 횟수 +1 | 인벤토리 0 임박 시 | 재구매 대안(소액 절약) |
| 그릇 매칭 리롤 | 플레이팅 페이즈 그릇 1회 다시 추천/교체 | 플레이팅 화면 | 매칭 실수 구제 |
| 손님 취향 힌트 | 까다로운 손님의 요구 1축 더 공개 | 식사 전 | 후반 미식가에 유효 |
| 실패 부활 | 라운드 실패 시 1회 재시도(재료 소모 면제) | 실패 직후 · **1회/라운드** | 명품 손실 압박 완화 |
| 일일 보너스 | 출석 보상(소액 자금/재료) | 하루 1회 | 리텐션 |
| 시장 정보 미리보기 | 시장 이벤트·한정 입고·새벽 경매 물량 사전 확인 | 시장 화면 | 재방문·동선 계획 유도(`markets-v1 §4`) |
> 원칙: 광고는 **진행을 사지 않음**(편의·구제만). 광고 없이도 클리어 가능하도록 경제 밸런스 유지(`economy §5` 페이스).
> 배너/전면: 라운드 종료 후 전면 1회(저빈도), Remove Ads IAP로 제거(보상형은 유지) — 기존 CLAUDE.md 수익 모델과 정합.

## 2. 컬렉션 DLC 팩 (고정 콘텐츠, 가챠 X)
각 팩 = **메뉴 + 캐릭터 + 그릇/도구**의 고정 묶음. 한식 지역·테마 컬렉션으로 정체성 강화.
| 팩 | 구성(예) | 테마 |
|---|---|---|
| 전주 한정식 팩 | 메뉴 4(비빔밥 고급형·전주식 반찬상 등) + 캐릭터 1~2(전주 명인) + 유기 그릇·도구 | 한정식 정점 |
| 부산 해산물 팩 | 회·생선구이·해물탕 메뉴 + 캐릭터(자갈치 상인) + 옹기·돌솥 | 해산물 |
| 궁중요리 팩 | 구절판·신선로·궁중떡볶이 + 캐릭터(수라간 상궁) + 명품 도자기 | 전통 궁중 |
| 길거리 음식 팩 | 호떡·붕어빵·떡꼬치 + 캐릭터(포장마차 사장) + 나무소반 | 분식·노포 |
> DLC는 **고정 가격·고정 내용**(가챠/확률 없음). 본편 진행을 막지 않음(선택적 컬렉션 확장).
> 팩 캐릭터도 미각 프로파일·인격 골격(`characters-v2`) 동일 적용.

## 3. 구조 요약
```
무료 본편(엔딩까지 가능) ── 광고 보상(선택 편의/구제) ── DLC 팩(선택 컬렉션 확장)
                              + Remove Ads IAP(배너/전면 제거)
```

## 4. A/B 미결 (사용자 확인 필요)
- **[A/B] 실패 부활 빈도**: A=1회/라운드(디폴트) / B=일일 N회 공유. 디폴트 A.
- **[A/B] DLC 캐릭터의 평가 라인 편입**: A=별도 손님(디폴트) / B=평가자 라인 확장(골든스푼 외 지역 평가단). 디폴트 A.
- **[A/B] 광고 손님 힌트 공개량**: A=1축 추가(디폴트) / B=풀 힌트. 디폴트 A(탐색감 유지).
