## 2. 평판 (Phase 1, 2티어까지)
| 단계 | 효과 |
|---|---|
| 뜨내기 | 정가, Basic만 |
| 안면 텄음(1) | −5%, 제철 정보 |
| 단골(2) | −10%, **특산품 해제** |
> Phase 1은 특산품(2티어)까지. VIP·명품·새벽 경매 입찰은 Phase 2 archive. 평판은 그 시장 재료로 만든 요리가 호평받을수록 ↑.

## 3. 시장 방문 UX (functional, 가볍게)
메인 → 시장 선택(동네/노량진 2버튼) → **가판대 위젯**(가로 스크롤, 풀 일러스트 X) → 단골 상인 한 줄 → 재료 선택·구매. 정적 BG + ambient loop.

## 4. 가격 차등 (간단)
- 해산물·죽방 멸치: 노량진 최저가. 동네에선 +20% 또는 미취급(생선류).
- 기본 재료(쌀·장·채소): 동네 기준가.
- 평판 단골(2) 시 −10%.
> 수식 = `economy-balance-v1`(풀) §8 준용, Phase 1은 2시장·2티어로 축소.
