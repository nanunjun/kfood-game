## 0. 핵심 원칙

- **One-thumb / 5-second rule** 준수. 모든 step은 한 손가락 + 5초 안에 의도 파악.
- **Anchored CTA**: 각 step 끝에는 단일 highlighted 다음 액션 (선택 분기 없음).
- **Skip 정책**: Step 1 강제(skip 불가), Step 2~4는 우상단 `Skip All` 가능. 한 번 skip 시 영구.
- **광고 차단**: FTUE 5분 이내 Interstitial **무조건 차단** (GDD §5.2). Banner는 메인 메뉴 도달 후 노출.
- **첫 음식 = 라면 lock** (v0.3, N-1 sync 자동 결정). 근거: 호떡 supersede 후 2가게 음식 0개, 라면이 다음 단순 음식 후보 1순위.

## 1. FTUE 첫 음식 — 라면 lock (v0.3 신규)

| 후보 | 가게 수 | 재료 수 | 조리법 | Stage 3 cook_time | 결과 |
|------|--------|--------|--------|-------------------|------|
| **라면** | **3 (🥬+🌾+🫙)** | 3 | 끓이기 | 9s | ✅ **LOCK (v0.3 1순위 신규)** |
| 잔치국수 | 4 (🥬+🐟+🌾+🫙) | 8 | 끓이기 | 12s | 2순위 — Round 2 후보 (어물전 데뷔 좋으나 8재료 + 4가게가 FTUE 첫 음식에 부담) |
| 콘도그 | 3 (🥩+🌾+🫙) | 6 | 튀기기 | 8s | ❌ (재료 6 + 튀기기 도입 = FTUE 부담) |
| 김밥 | 5 (전 가게) | 6 | 말기 | 4s | ❌ (FTUE에 5가게 풀 순회 부담) |

**라면 lock 사유** (v0.3, N-1 sync 자동 결정 + game-designer mvp-food-selection v2.2 §FTUE 권고):
- **3가게 = FTUE 다점포 학습에 최소 진입**. 호떡(2가게) supersede 후 MVP 음식 중 가장 단순 가게 수. Step 1 단일 가게(🌾 곡물상 라면사리) → Step 2 2가게 확장(🌾+🫙 계란 추가) → Step 3 3가게 풀(🥬 파 추가) 자연 ramp.
- **재료 3개 (라면사리/계란/파)** = MVP 최저. Step 1 단일 정답(라면사리), Step 2 +1정답(계란), Step 3 +1정답(파) 점진 학습 — step별로 정답 재료 1개씩만 늘어남.
- **끓이기 조리법** = T1 최다 음식 공유 (떡볶이·잔치국수·라면 3음식). FTUE에서 익힌 끓이기 메커닉이 Round 2~6에서 즉시 재사용 → 학습 효율 ↑.
- **글로벌 SS급 인지도** = D1 retention hook. "Ramen" 영어권 일반화 + 즉석라면 (Korean instant ramen) 글로벌 viral SKU (신라면·진라면 등).
- **cook_time 9s** = Step 3 timing 학습에 적정 (4s 김밥은 너무 짧음, 12s 잔치국수는 길게 느껴짐).
- **단점 보상**: 호떡 대비 시각 매력 3/5(호떡 5/5)이라 Scene 3 첫 인상 임팩트 약화 → Step 4 식탁 reaction Happy 표정 + 한국 즉석라면 "포장지 → 냄비" 시각 메타포로 K-pop 정서 임팩트 보완.

> **호떡 제거 사유 (v0.3)**: v2.2 mvp-food-selection N-1 lock으로 호떡이 MVP 음식에서 제외됨 (post-launch M1 디저트 카테고리 부활 후보). FTUE 첫 음식 1순위 자리는 자동으로 라면으로 이동.

> **잔치국수 2순위 의의 (v0.3 신규)**: 명절·잔치 시그니처 + 어물전 데뷔(멸치). 단 **4가게 + 8재료**가 FTUE 첫 음식에 부담 → **Round 2 또는 Round 3 후보**로 격리. FTUE 종료 후 첫 자유 플레이 음식으로 잔치국수 제시 시 "어물전 첫 등장" 정서 임팩트 활용 가능.

> **계란말이 제거 사유 (v0.2 이전 기록)**: v2.0에서 음식 12개 reshuffle로 계란말이가 MVP에서 제외됨. FTUE 첫 음식 1순위 자리는 호떡 → 라면 순으로 이전.

## 2. 4-Step 흐름 (Overview)

```
[첫 부트 → Splash → Main Menu (skip) → Level 1 자동 진입]
       │
       ▼
┌──────────────────────────────────────────────┐
│ Step 1 — 단일 가게 raw introduction          │
│   Scene 1 입구(가게 1개만, 🌾 곡물 활성) →   │
│   가게 진입 → 재료 픽업 → 자동 진행           │
│   음식: 라면 (raw, 곡물 가게만 활성)          │
│   → Step 1 한정 라면 재료 부분집합(라면사리)  │
└──────────────────────┬───────────────────────┘
                       │ Round 종료 후 (Scene 2·3 임시 skip)
                       ▼
┌──────────────────────────────────────────────┐
│ Step 2 — 다점포 개념 도입 (2가게)             │
│   가게 2개 활성 (🌾 곡물 + 🫙 잡화)           │
│   음식: 라면 (라면사리 + 계란)                │
│   → 같은 음식 확장 = 학습 강화                │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ Step 3 — Scene 2 키친 첫 등장                │
│   조리법 선택 UI 첫 노출 → Stage 3 timing    │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│ Step 4 — Scene 3 식탁 첫 등장                │
│   점수 / ★ / "잘했어요" 피드백 첫 노출        │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
                [FTUE 종료, Level 1 정식 진입]
```

### 2.1 전체 소요 시간 목표

- Step 1: ~30s
- Step 2: ~45s
- Step 3: ~45s
- Step 4: ~30s
- **합계 목표: 2.5~3분** (FTUE 5분 이내 광고 차단 룰 안전 마진).

> **Step 1 라면 raw introduction 노트 (v0.3)**: 라면 본 SKU는 곡물(라면사리) + 잡화(계란) + 청과(파) = 3가게 3재료. Step 1은 **곡물 측 정답 1개(라면사리)만** 노출(FTUE 한정 부분집합). Step 2에서 잡화점 추가 활성 시 계란 픽업 = 같은 음식 확장 학습. Step 3에서 청과상 추가 시 파 픽업 = 3가게 풀 순회 완성.

### 3.2 Step 1 룰

- **타이머 표시 없음** (압박 제거).
- **오답 카드 비활성** (정답만 탭 가능 — 첫 인지 부담 0).
- **정답 글로우 표시** (cooking-mech §2.4 룰 예외 — FTUE 한정).
- **공통 타이머 비표시** (Stage 1 핵심 UI는 step 2부터 노출).
- **Scene 2·3 자동 스킵**: Step 1 종료 직후 Step 2 ramp-up 모달로 이동 (조리·식탁은 step 3·4에서 첫 노출).

### 3.3 Step 1 anchored CTA & 사운드 hook

| 시점 | CTA / 안내 | 사운드 hook |
|------|----------|------------|
| 입구 진입 | "곡물상에 가볼까요?" + 👆 | 🔊 `ftue_voiceover_step1` (TBD) |

## 4. Step 2 — 다점포 개념 도입 (2가게)

### 4.1 화면 흐름

```
[Step 1 종료 직후, 짧은 모달 0.8s]
   │
   ▼
┌────────────────────────────────────────┐
│  💡 "이번엔 2개 가게를 둘러봐요"        │
│        [ 좋아요 ]                       │
└────────────────────────────────────────┘
   │ 탭
   ▼
┌────────────────────────────────────────┐
│  📝 요리 카드: "🍜 라면 (1인분)"        │
│     (같은 음식 확장 = 학습 강화)         │
├────────────────────────────────────────┤
│   ┌──┐       ┌──┐                      │
│   │🌾│       │🫙│  ← **2개 활성**       │
│   │곡│       │잡│                      │
│   │물│       │화│                      │
│   └──┘       └──┘                      │
│   ┌──┐ ┌──┐ ┌──┐                       │
│   │🔒│ │🔒│ │🔒│  ← 3개 회색 잠금       │
│   └──┘ └──┘ └──┘                       │
│                                        │
│   💬 "두 가게를 다 다녀와야 해요"        │
│   ⏱ ▓▓▓▓▓░░ 25s (타이머 첫 노출)       │
└────────────────────────────────────────┘
```

### 4.2 Step 2 룰

- **2가게 활성** (🌾 곡물 + 🫙 잡화) — 라면 부분집합(라면사리 + 계란)에 정확히 fit. 청과(파)는 Step 3에서 추가.
- **타이머 첫 노출** (25s, 넉넉 — 압박 최소화).
- **정답 글로우 OFF** (탐색 학습 시작).
- **오답 탭 활성** (페널티는 있으나 빨간 shake로 학습).
- **빈 가게 진입은 트리거 X** (활성 2가게 모두 정답 있음).
- 모든 정답 픽업 → 자동 입구 복귀 → Step 3 모달.

### 4.2.1 Step 2 음식 권고 재검토 (v0.3 갱신, N-1 sync)

> **결론: Step 2도 라면 그대로 유지 권고.** 라면 본 SKU 3가게(곡물+잡화+청과) 중 Step 1(곡물 단독: 라면사리) → Step 2(곡물+잡화: 라면사리+계란) → Step 3(곡물+잡화+청과: 라면사리+계란+파) 점진 학습. 별도 음식 swap 불필요.

- **v0.2 호떡 lock 폐기 사유**: 호떡 (t1_001) MVP 음식에서 제거됨 (N-1 lock 2026-05-30, mvp-food-selection v2.2). 라면(3가게)은 호떡(2가게) 대비 +1 가게 학습 부담이 있으나, 부분집합 노출 정책(Step 1 곡물만 / Step 2 곡물+잡화)으로 사용자 인지 부담은 동일 (2가게씩 점진).
- **검토했던 대안 (v0.3 신규)**: Step 2에서 잔치국수(4가게+8재료)로 swap → **거절**. 잔치국수는 부담이 더 큼 (재료 8개 + 어물전 데뷔). 라면 단독 4-step 유지가 학습 효율 ↑.
- **김밥 step 3 미루기 (v0.2 유지)**: 김밥은 5가게 풀 순회 = FTUE에 부적합 → 본 문서 §1 표에서 이미 제외.
- **단순 음식 후보 (FTUE 종료 후 본 게임 Round 2+ 권고)**: **잔치국수**(4가게, 끓이기, 어물전 데뷔, 명절 정서) → 떡볶이(4가게, 끓이기, 어묵 SKU)는 game-designer §3 난이도 곡선과 동기. FTUE 4-step은 라면 단일 음식으로 통일.

### 4.3 다점포 안내 반복 (cooking-mech §10.2 follow-up)

> **결정: 다점포 안내는 FTUE Step 2에서 1회만 강제. 이후 Round 2~3에서 미세 hint 1회 반복.**

| Round | 다점포 hint |
|-------|------------|
| FTUE Step 2 | "두 가게를 다 다녀와야 해요" (강제 모달, 스킵 불가) |
| FTUE 종료 후 Round 2 (잔치국수 또는 떡볶이 권고) | 입구 진입 시 토스트 "가게 여러 곳을 둘러봐요" 2.0s (스킵 가능) — 잔치국수는 4가게 + 어물전 데뷔라 다점포 학습 강화에 fit |
| Round 3+ | 미표시 (학습 완료 가정) |
| **김밥/떡국(5가게 풀 순회) 첫 등장 시** | 요리 카드 옆 ⓘ 아이콘 + "이 요리는 5가게 모두 필요해요" 토스트 |

⚙️ **확정 필요**: Round 2 미세 hint 횟수 — 1회 vs 2회 (Round 2·3 모두).

### 5.2 Step 3 룰

## 7. 친구 unlock 컷씬 — FTUE 일부 아님 (혼동 방지)

> **명시 (v0.2 갱신)**: 어머니/아버지 동시 unlock 컷씬은 **L11 Tier 2 진입 시점**에 1회성 트리거되며, FTUE 4-step과는 **별개**.

- FTUE = Level 1 첫 1 Round 한정 (Step 1~4, **라면 v0.3**).
- **어머니 + 아버지 동시 unlock** = L11 Round 1 직전 1회성 컷씬 ([`tier-1-2-flow.md`](tier-1-2-flow.md) §3.4). v0.1의 "어머니 L11 / 아버지 L15 분리" 권고는 **폐기** (game-designer 권고 채택 → Tier 2 진입 = 가족 식탁 풀 등장).
- 컷씬 skip 가능, FTUE의 `Skip All` 과는 독립.

이유: FTUE는 **메커닉 학습**, unlock 컷씬은 **정서 arc 발화** (혼밥 → 가족). 두 목적이 다르므로 UX 분리. 양친 동시 unlock은 Tier 경계의 정서 임팩트를 단일 컷씬에 집중하여 분산을 피한다.
