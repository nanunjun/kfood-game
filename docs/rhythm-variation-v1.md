# Rhythm Variation v1 — 리듬 변주 곡선 (장시간 비지루)

> 코어 리듬 라운드를 레벨·음식별로 변주해 5시간+에도 신선하게. 입력 코어(탭/홀드/스와이프)는 유지, **패턴·BPM·음식 특수성**을 변주.
> 연동: `GDD-v2 §9.5`, `scoring-v2`(양념 탭), `characters-v2`(레벨).

## 1. BPM 곡선 (레벨별)
| Lv | 1~3 | 4~6 | 7~9 | 10~11 | 12 |
|---|---|---|---|---|---|
| BPM | ~80 | ~95 | ~115 | ~135 | ~160 |
> 점증으로 손끝 긴장 상승. 손질·조리·양념 페이즈가 각 BPM에 맞춰 비트.

## 2. 패턴 복잡도 단계 (점진 해제)
| 단계 | 패턴 | 등장 | 설명 |
|---|---|---|---|
| P1 | **단일 탭** | L1~ | 비트에 한 번 탭 |
| P2 | **더블 탭** | L4~ | 연속 2탭(빠른 손질) |
| P3 | **홀드** | L6~ | 길게 눌러 유지(끓이기·담그기) |
| P4 | **양손 동시** | L9~ | 왼=칼/손질, 오=양념 동시 입력 |
| P5 | **순간 멀티** | 다인 | 게스트별 입력이 겹쳐 순간 다중 탭 |
> 한 번에 한 패턴씩 추가(온보딩 정합). 후반 = 여러 패턴 혼합.

## 2.5 노트 종류 분류 (양념 직관성, scoring §1.5)
| 노트 | 외형 | 입력 | 용도 |
|---|---|---|---|
| 일반 리듬 노트 | 표준 색·원형 | 단일/더블 탭 | 손질·조리 타이밍 |
| **양념 노트(tap-count)** | **양념통 아이콘 + 양념색**(고춧가루=빨강 등) | 탭 N회 = N단위 | 빠른 음식(분식) 양 입력, 색 게이지 누적 |
| **양념 노트(hold)** | 양념통 아이콘 + 길쭉한 홀드 바 | 누르는 시간 = 양 | 정밀 음식(한정식) 정량감 |
| 홀드 노트 | 길쭉한 바 | 길게 유지 | 끓이기·담그기 |
| 양손 노트 | 좌(칼)·우(양념) 동시 | 양손 동시 | 후반·다인 |
> 양념 노트는 일반 노트와 **색·아이콘으로 명확 구분** + 화면 게이지와 연동돼 "몇 번 넣었는지" 항상 보임. 입력 방식(tap/hold)은 음식 데이터로 지정.

## 3. 음식별 특수 조리 (리듬 정체성)
| 토큰 | 음식 | 특수 리듬 |
|---|---|---|
| CUT-xx | 대부분 | 비트에 맞춰 썰기 탭(BPM 연동) |
| DIP-00 | 콘도그 | **담그기 홀드** — 반죽에 담가 일정 시간 유지 후 떼기 |
| MAR-00 | 불고기 | **재우기 슬로우탭** — 느린 비트로 양념 주무르기(부드러운 리듬) |
| FRY | 튀김(콘도그·해물파전 일부) | **리듬 가변** — 기름 온도에 따라 비트 간격 흔들림 |
| ROLL | 김밥 | **연속 스와이프** — 비트에 맞춘 말기 드래그 |
| BOIL | 라면·잔치국수·순두부 | **보글 홀드+탭** — 끓는 동안 홀드, 거품 타이밍 탭 |
> 음식이 곧 미니게임 변주 → "또 같은 거" 방지.

## 5. 다인 디너 입력 변주
- 게스트별 양념 목표가 달라 **순간 멀티 입력**(P5): 동시에 두 그릇/두 양념 비트가 뜨면 양손으로 분배.
- 엔드게임 4인 코스 = 양손 + 빠른 BPM + 홀드 혼합의 합주.

## 6. A/B 미결
- **[A/B] 양손 동시 입력**: A=L9부터 도입(디폴트) / B=옵션 토글(접근성). 디폴트 A + 접근성 옵션 병행 권장.
- **[A/B] BPM 상한**: A=160(디폴트) / B=180(하드코어). 디폴트 A.
