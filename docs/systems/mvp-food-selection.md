### 0.1 사용자 결정 컨텍스트 (verbatim 2026-05-30)

> "잔치국수가 좋을거 같고, 순두부나 김치찌게 중에 하나도 다른거로 바꿨으면 해...둘다 찌게 종류라 MVP에서는 다른 종류의 음식이 더 나을거 같음"
>
> 후속 선택: **"순두부 유지 + 김치찌개 → 불고기"**

**N-1 채택 사유 (game-designer 보강)**:
- 호떡 = 디저트/길거리 음식. cooking matching의 "재료 다양성 + 조리 순서" 게임플레이 fit 약함 (2가게, 5재료 중 3개가 잡화 코너 = "잡화점에서 다 사오기" 단조로움).
- 잔치국수 = 정통 한식 면 요리. 곡물(소면) + 잡화(다진 마늘·간장) + 어물(멸치 육수)이 **3가게 순회**로 메커니즘 명료.
- 명절·잔치 시그니처 = 친구·가족 정서 arc(L11 어머니/아버지 등장)에 hook.
- **어물전 floor 유지/강화**: 호떡(어물전 0회) → 잔치국수(어물전 1회: 멸치) = floor 5 유지 확정 (§2.1).

**N-2 채택 사유 (game-designer 보강)**:
- v2.1 T2 = 끓이기 2개(김치찌개 + 순두부찌개) 카테고리 중복. 사용자 직관(찌개 2종 = MVP 다양성 약화) 정확.
- **순두부 유지 결정**: 순두부찌개는 v2.1 C-2 lock에서 **T2 어물전 단독 책임 음식**(멸치 육수)으로 구조적 의의. 제거 시 어물전 floor 4로 회귀. → 김치찌개 교체로 결정.
- 불고기 = K-BBQ 시그니처. 단맛 양념 marinade(간장+설탕+배+마늘) + thin sliced beef + 채소(양파·대파·당근·표고) mixed = 잡채와 다른 정육 메커닉.
- **F-12 갈비구이와 차별화**: 갈비구이 = bone-in LA-cut grilled, 직화·타이밍 핵심. 불고기 = boneless thin-slice + 양념 marinade rhythm tap (60 BPM, ADR-005 양념재우기 cut style) + 볶기/끓이기 hybrid (전골식). 시각·메커닉 모두 분리 가능 (§F-12 차별화 §1.5 신설).

### 1.6 F-12 갈비구이 vs F-09 불고기 차별화 매트릭스 (v2.2 신규)

| 축 | F-09 불고기 | F-12 갈비구이 |
|----|-----------|-------------|
| **고기 형태** | thin-sliced boneless (1~2mm) marbled sirloin | **bone-in** LA-cut (3cm thick cross-section, visible white rib bone) |
| **양념** | sweet marinade pool (간장+설탕+배+다진마늘+참기름) — **재우기 필수** | sweet marinade brush (간장+설탕+배즙) — 표면 코팅 위주 |
| **조리법** | **양념 재우기 + 볶기** (전골 팬 or 스킬렛) | **굽기 (직화)** — grill grate + flame |
| **채소 동반** | **mixed**: 양파·대파·당근·표고 함께 볶음 | **separate**: 상추 ssam + 마늘·풋고추 곁들임 |
| **plate 비주얼** | 갈색 양념 코팅 strips + 채소 mixed in pan/dish | 검정 grill grate 위 LA cross-cut + 불꽃·연기 |
| **cook_time** | 16s (양념 8s + 볶기 8s) | 18s (직화 길게) |
| **perfect_window** | 900ms (T2 standard) | 650ms (사용자 명시 "타이밍 핵심") |
| **difficulty_score** | 4 | 5 (MVP 최고) |
| **ADR-005 cut style** | 양념재우기 60 BPM + 양파 채썰기 115 BPM | 양념재우기 60 BPM (마늘) 단독 |
| **글로벌 인지도** | "bulgogi" 영어 외래어 | "Korean BBQ" / "galbi" 영어 외래어 |
| **art-director anchor risk** | DALL-E 일본 sukiyaki 누수 ~40% — **brown marinade pool** + Korean sliced beef silhouette 명시 | DALL-E 일본 야키니쿠 누수 60%, 미국 BBQ ribs 30% — bone visible + LA-cut 명시 (v1.13 risk lock 유지) |

**판정**: 시각·메커닉·정서 3축 모두 분리 가능. **MVP T2 정육 음식 3종**(불고기·갈비구이·잡채)이 각각 양념재우기/굽기/볶기-무치기로 조리법 carrier 다양 → **T2 정육 카테고리 메커닉 학습 풍부함 +1**.

```
난이도 5 ┤                                       ┌──
난이도 4 ┤                    ┌─────┐  ┌─────────┘
난이도 3 ┤            ┌───────┘     └──┘
난이도 2 ┤   ┌────────┘
난이도 1 ┤───┘
        └──────────────────────────────────────

```

- T1 진입의 라면(1) → 잔치국수(2) → 떡볶이(2) ramp가 v2.1(호떡 2 → 라면 1 → 떡볶이 2)보다 부드러움 (1 → 2 → 2 단조 증가).

- 잡채 단독 L15~L19 리스크(v2.1 잔존) 유지 — post-launch M1 양념치킨 부활 시 보강 후보.
