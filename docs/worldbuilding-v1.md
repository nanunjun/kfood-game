# Worldbuilding v1 — 한식 명인이 되는 여정 (Journey to 한식 명인)

> 정체성 정식화. 이 게임은 **평범한 일반인이 한식 장인이 되어가는 영웅 서사**이고, 세계는 **한국 전통시장**을 허브로 굴러간다. 추상적 "재료 구매" 메뉴를 실제 시장 월드로 대체.
> 연동: `GDD-v2`(정체성), `markets-v1`(시장), `characters-v2`(손님·상인), `unlock-tree-v1`(시장·레벨), `economy-balance-v1`(가격·평판).

## 1. 컨셉 한 줄
> **"한식 장인이 되는 여정 — 한국 전통시장을 누비며 손님·도구·그릇·재료·메뉴를 수집한다."**
무명의 부엌에서 시작해 동네·시장 단골을 거쳐 지역 명인, 끝내 **한식 명인**에 이르는 성장 서사.

## 2. 영웅 서사 구조 (성장 단계)
```
무명 ─▶ 동네 ─▶ 시장 단골 ─▶ 지역 명인 ─▶ 한식 명인
부엌    가족·이웃   시장 누빔     입소문·평가     골든스푼·거장
```
- **소명(Call)**: 엄마에게 차린 첫 상. "이 길로 가볼까?"
- **시련(Trials)**: 점점 까다로운 손님·평가자. 시장에서 더 좋은 재료를 찾아 나섬.
- **조력자(Allies)**: 시장 상인들(단골·할인·정보), 친구들.
- **관문(Threshold)**: 골든스푼 평가관(떡밥 L3 → 회수 L10).
- **귀환/완성(Return)**: 한식 명인 칭호, 자유 플레이.

## 3. 세계관 = 시장 허브
- 메인 허브 = **자주 가는 시장**. 메뉴에서 시장 선택 → 가판대 스크롤 → 단골 상인과 짧은 대화 → 구매.
- 각 시장은 **고유 분위기·BGM·환경음·특산·상인**을 가짐(상세 `markets-v1`).
- 시장 **평판**이 오르면 명품 재료·도매가 인하·한정 이벤트(새벽 경매 등) 개방.
- 진행하며 시장이 하나씩 열려 "내 단골 동선"이 형성됨.

## 5. 톤 가이드 (월드 비주얼·서사)
- **시장 비주얼**: 진짜 한국 전통시장 디테일 — 빨간 차양, 파란/빨간 플라스틱 박스, 종이상자, 생수통, 스티로폼 박스, LED 빨간 가격표, 손글씨 가격판, 천막. **미화하지 말되 따뜻하게**(정겨움·생활감). 양식화는 premium v2 톤.
- **상인 NPC**: 한국적 정·구수함. 디테일한 말투. 부산·전주는 방언 한두 마디(과하지 않게).
- **시간대**: 시장 BG는 시간대 변주 가능 — 새벽 경매(푸른 새벽빛)·낮(밝은 활기)·저녁 마감세일(주황 노을·"떨이").
- **서사 톤**: 거창한 판타지 영웅담이 아니라 **생활밀착형 성장기**. 소박한 시작, 진심 어린 손님, 따뜻한 승리.

## 6. A/B 미결 (사용자 확인 필요)
- **[A/B] 컷씬 분량**: A=레벨당 1~2장 + 2~3문장(디폴트, 경량) / B=풀 컷씬(아트 비용↑). 디폴트 A.
- **[A/B] 시간대 변주 범위**: A=핵심 시장만 새벽/낮/저녁 3종(디폴트) / B=전 시장 시간대(아트량↑). 디폴트 A.
- **[A/B] 방언 강도**: A=한두 마디 양념(디폴트, 가독성) / B=풀 방언 대사. 디폴트 A.
