# research/

시장·경쟁작·유저 리서치 자료.

## 무엇을 두는가
- **경쟁작 분석**: Merge Mansion, Gossip Harbor, Travel Town, EverMerge 등
  - 핵심 루프 분해, 수익화 구조, FTUE, 리텐션 훅
- **시장 데이터**: data.ai / Sensor Tower / AppMagic 스크린샷·CSV
- **유저 리서치**: 설문 결과, 플레이테스트 노트, 인터뷰 녹취
- **트렌드**: 한식 트렌드, K-콘텐츠 인기 지표
- **수익화 벤치마크**: 동장르 LTV, ARPDAU, ad placement 패턴
