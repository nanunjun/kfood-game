## 0. 한 줄 요약

> **Tier 1 = 혼밥 + 가벼움 + 친구 0명. Tier 2 = 가족 + 무게감 + 어머니/아버지 L11 동시 unlock.**
> 같은 3-Scene 골격을 유지하되, Scene 3 식탁 구성 / 카드 개수 / 시간 압박 / 광고 빈도가 **점진적으로** 올라간다.
> v0.2 변경: 어머니/아버지 분리 unlock(L11/L15) 권고 폐기 → **양친 동시 L11 unlock** 채택.

## 1. 비교 매트릭스 (한눈)

| 영역 | Tier 1 (L1~10, 혼밥) | Tier 2 (L11~25, 가족) | 변화량 |
|------|---------------------|----------------------|--------|
| 인분 표기 | "1인분" 배지 (요리 카드 좌상단) | "2인분" 배지 (분홍 강조) | text + 색상 |
| 재료 카드 개수 | 3~6개 (가게당 1~2 + 디스트랙터 0~1) | 5~7개 (가게당 1~2 + 디스트랙터 1~2) | +2개 평균 |
| Stage 1 타이머 | 15~22s | 22~30s | 더 길어지지만 재료 많아 압박 동일 |
| Stage 3 PERFECT 폭 | 10~15% (default~넉넉) | 8~10% (default~타이트) | -2~5% |
| Scene 3 인원 | 1인 (주인공만) | 2~3인 (주인공 + 어머니 [+ 아버지]) | +1~2 캐릭터 |
| Scene 3 BG | 작은 1인 상 | 큰 가족 식탁 + 중앙 찌개/메인 요리 | 별도 BG asset |
| 점수 표시 톤 | "잘했어요!" 친근 | "가족이 좋아해요!" 정서적 가중 | 카피 차이 |
| 친구 첫 등장 | — | **L11 어머니/아버지 동시 unlock 컷씬** | 1회성 cinematic (양친 동시) |
| 광고 Interstitial | 3 레벨마다 1회 | 3 레벨마다 1회 (동일) | 동일 |
| 광고 Rewarded 노출률 | 낮음 (FTUE 영향) | 평균 (난이도 ↑ → 자발 시청 ↑) | 자연 증가 |

## 3. Scene 3 식탁 구성

### 3.1 Tier 1 — 혼밥 식탁

- BG: 1인 작은 상, 단일 펜던트 조명
- 캐릭터: 주인공 1인 (3/4 시점)
- 음식: 작은 그릇 1개 (혼밥용)
- 톤: 조용한 따뜻함 — art-style §4.4 "식탁 (혼밥)" 소품 카탈로그

### 3.2 Tier 2 — 가족 식탁 (양친 동시, v0.2)

- BG: **3인 가족 식탁**, 가운데 큰 찌개/메인 + 반찬 4~6종, 따뜻한 펜던트 조명
- 캐릭터: 주인공 + **어머니** + **아버지** (L11 이후 항상 3인 일관)
- 음식: 중앙 큰 그릇(찌개/볶음/구이) + 개인 밥공기 3
- 톤: 따뜻함 + 정 — art-style §4.4 "식탁 (가족)" 소품 카탈로그
- 가운데 2인(어머니/아버지) 추가 등장으로 식탁 무게중심이 화면 중앙으로 이동 → 혼밥 1인 BG 대비 정서 임팩트 극대화

### 3.3 친구 캐릭터 등장 타이밍 (v0.2 lock)

> **결정 lock (game-designer 권고 채택)**: 어머니/아버지 **L11 동시 unlock**. v0.1의 "어머니 L11 / 아버지 L15 분리" 권고는 폐기.

| 캐릭터 | 등장 시점 | UI 트리거 | 사유 |
|--------|----------|----------|------|
| 주인공 | L1 (FTUE 첫 음식부터) | — | 항상 존재 |
| **어머니** | **L11 Tier 2 진입** | Level Select → 양친 동시 unlock 1회 컷씬(스킵 가능) | Tier 경계 = 정서 arc 발화 지점 |
| **아버지** | **L11 Tier 2 진입 (동시)** | 위 동일 컷씬에서 함께 등장 | 가족 식탁 풀 등장 → Tier 2 정서 임팩트 single peak |

**채택 사유**:
- **Tier 2 진입 = 가족 식탁 풀 등장** 단일 임팩트로 집중. 분리 unlock(L11/L15)은 컷씬 임팩트 분산 + L11~14 "2인 가족" 어색 BG 발생.
- **reaction anchor 6컷 sleeping 회피**: art-style §3.5 reaction sheet(어머니 ★1/2/3 + 아버지 ★1/2/3 = 6컷)이 L11부터 즉시 활용된다. L15 분리 시 아버지 3컷이 L11~14 동안 sleeping → 자산 ROI 손실.
- L11~25 식탁 = 주인공 + 어머니 + 아버지 (3인 일관).

#### 3.3.1 L11 → L15 단계적 reaction 다양성 흐름

양친이 L11에 동시 등장하지만, **reaction 다양성은 L11 → L15 사이에 단계적으로 노출**되도록 권고:

| 레벨 구간 | reaction 노출 |
|----------|--------------|
| L11~12 | 양친 모두 **Subtle 중심** (★1·★2 위주). 첫 인사·관찰 톤. ★3 메시지는 "조용한 만족" 카피로 약하게 |
| L13~14 | ★3 시 **어머니 Happy** 먼저 노출 (어머니가 정서 anchor). 아버지는 여전히 subtle |
| L15+ | **양친 Happy 동시 트리거** (★3 시) + 선호도 매칭 시 0.3s 시차로 reaction 가중 |

> 이 단계 흐름은 reaction anchor 6컷을 L11~15에 점진 노출하여 컷씬 후 "한 번에 모든 표정을 다 본 피로"를 회피한다.
> ⚙️ 정확한 레벨/카피는 game-designer balance-config sync.

### 3.4 양친 동시 unlock 컷씬 UI (v0.2 재작성)

```
[Level Select에서 L11 탭 — "Tier 1 완주" 모달 직후]
   │
   ▼
┌────────────────────────────────────────┐
│   화면 페이드 → 가족 식탁 BG 풀스크린   │
│      (art-style §4.4 "식탁 가족"        │
│       골든아워 펜던트 조명 동일 톤)     │
│                                        │
│   ✨ "오늘부터 가족이 함께해요"          │
│                                        │
│   ┌────────┐ ┌────────┐ ┌────────┐     │
│   │ 어머니  │ │ 주인공  │ │ 아버지  │   │
│   │ (3/4)  │ │ (정중앙)│ │ (3/4)  │   │
│   │ CH-02  │ │ CH-01  │ │ CH-03  │   │
│   └────────┘ └────────┘ └────────┘     │
│      ↑ Subtle      ↑          ↑ Subtle│
│      (첫 인사 미소, 양친 동시 fade-in   │
│       0.6s 시차 — 어머니 → 아버지)     │
│                                        │
│   💬 "오늘 뭐 먹을까?" (어머니 말풍선)   │
│   💬 "맛있는 거!" (아버지 말풍선, 0.5s) │
│                                        │
│        [ 함께 요리하기 ]                │
└────────────────────────────────────────┘
   │ 4.0s 자동 또는 탭 스킵
   ▼
[L11 Round 1 시작 — Tier 2 첫 음식]
```

**컷씬 톤 (정서 임팩트)**:
- 마스코트 art-style 톤(art-style §3 chibi 비율, mitten 손, 점 눈, 볼터치) 그대로 적용 — 정서 동기화.
- **혼밥 → 가족 전환의 단일 정서 peak**: L1~L10 동안 주인공 1인 식탁(작은 1인 상)으로 유지되던 화면이, L11 컷씬에서 한 번에 **식탁 가운데 2인(어머니/아버지) 추가 등장**으로 전환된다. 식탁 무게중심이 화면 중앙으로 이동하며 "혼자 → 셋이 함께"의 정서 변화가 단일 컷에 응축된다. 이 임팩트는 양친 분리 unlock(2단계 약한 peak)으로는 재현 불가능한 single big moment.
- 컷씬 직후 L11 Round 1부터 식탁 BG는 항상 3인 가족 식탁. 다시는 1인 BG로 돌아가지 않는다(retention 핵심 시그널).

**구현 노트**:
- 1회성, 스킵 가능 (탭 또는 우상단 `Skip`).
- BG asset 재활용: art-style §4.4 "식탁 (가족)" 풀스크린.
- 양친 Subtle 표정 anchor 사용 (CH-02 Subtle / CH-03 Subtle = reaction anchor 6컷 중 4컷).
- 사운드 hook (M2~M3 deferred): 🔊 `cutscene_family_unlock` (따뜻한 펜던트 + 가족 첫 인사 BGM).

## 4. 광고 트리거 빈도 차이 (GDD §5.2 Stream A)

### 4.1 Interstitial — Tier 무관 동일

- **3 레벨마다 1회** (GDD §5.2). Tier 1·2 동일.
- FTUE 5분 이내 차단 (L1~3 영향).
- IAP Remove Ads로 비활성화 가능.

### 4.2 Rewarded — Tier별 자발 시청 차이 (수동)

| Rewarded 트리거 | Tier 1 예상 시청률 | Tier 2 예상 시청률 | 차이 사유 |
|-----------------|-------------------|-------------------|----------|
| Stage 1 "힌트" | 낮음 (~10%) | 중간 (~20%) | T2는 재료 수 ↑ → 힌트 가치 ↑ |
| Stage 3 "PERFECT 폭 확대" | 낮음 (~8%) | 중간 (~15%) | T2 PERFECT 폭 8~10%로 타이트 → 광고 가치 ↑ |
| Scene 3 "한 번 더" | 낮음 (~5%) | 높음 (~25%) | T2 fail rate ↑ (cook_time 25s 갈비찜 등) |

> 수치는 캐주얼 모바일 평균 추정. **GDD §11.2 KPI 목표 = Rewarded 시청률 ≥25% (eligible 유저 기준)**. T2 비중이 누적 KPI 견인.
> 실제 수치는 M3 Closed Beta + 출시 후 A/B → data-analyst가 재보정.

### 4.3 Banner — Tier 무관 동일

- 메인 메뉴 / Level Select / 상점 / 설정 하단 고정.
- 게임플레이 Scene 1·2·3 노출 금지.

### 4.4 ⚙️ confirm 필요

- Interstitial 3 레벨마다 1회가 Tier 2에서도 적정한지 (Tier 2는 Round 길이 ↑로 광고 간격이 자연 늘어남) — A/B 후보. GDD 부록 follow-up.

## 5. 점수 표시 톤 차이

### 5.1 Tier 1 — 친근한 톤

| ★ | 메시지 | VFX |
|----|--------|-----|
| ★☆☆ | "잘했어요!" | 작은 sparkle |
| ★★☆ | "맛있게 먹었어요!" | 중간 sparkle + 별 1개 fade-in |
| ★★★ | "와! 최고예요!" | 큰 particle burst + 별 3개 stack |

### 5.2 Tier 2 — 가족 정서 가중

| ★ | 메시지 | VFX |
|----|--------|-----|
| ★☆☆ | "가족이 한 입씩 먹어요." | 작은 sparkle |
| ★★☆ | "엄마가 미소를 지어요." | 중간 sparkle + 어머니 reaction 강조 |
| ★★★ | "오늘 우리 집 최고의 식탁!" | 큰 particle burst + 가족 전원 Happy 표정 (어머니 + 아버지 동시) |

> 메시지 카피는 game-designer / 사용자 톤 검토 권고. ⚙️ **본 카피는 placeholder — 사용자 검토 필요 (v0.2 유지)**.
> §3.3.1 단계 흐름과 연동: L11~12 ★3 카피는 "조용한 만족" 톤 약화 버전, L13~14는 어머니 강조, L15+ 양친 동시 = 위 표 그대로.

### 5.3 친구 선호도 반응 (cooking-mech §5.1)

- 캐릭터별 `Friend.preferences` 매칭 시 reaction 가중치 ↑ (점수에는 영향 X, 정서 피드백만).
- Tier 1: 주인공만 = 선호도 없음 (UI 가중 없음).
- Tier 2: 어머니/아버지 선호도 매칭 시 → 해당 캐릭터 reaction 0.3s 먼저 트리거 + 작은 ♡ VFX.

⚙️ 어머니/아버지 personality + 호불호는 game-designer M0 작업 (mvp-food-selection §6.3). 양친 L11 동시 unlock으로 호불호 매칭 시각화는 L11부터 즉시 active.
