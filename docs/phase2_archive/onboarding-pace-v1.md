## 1.5 첫 화면 = 캐릭터 선택 (R0)
첫 실행은 **플레이어 프리셋 5종 캐러셀**에서 시작(`player-characters-v1`). 선택 → 이름 커스텀 → 캐릭터별 오프닝 컷씬 3씬(톤만 다름) → R1. 선택은 메커닉 무영향, 서사·아바타·NPC 인사 톤만 분기.

## 2. 첫 라운드(R1) 세부 — 코어만
- 메뉴: 라면(친숙). 재료 5~6종 **자동 보충**(인벤토리 UI 없음).
- 도구 1티어, 그릇 1~2종, **매칭 비활성**.
- 양념: 탭으로 양 넣기 → **자동 통과**(엄마는 다 맛있어함).
- 캐릭터: 엄마만. 결과: "딱 좋았어!" + 별, 따뜻한 칭찬.
> 목표: "썰고-끓이고-양념하고-담아내니 손님이 좋아한다"는 **코어 한 바퀴 체득**.
